# 智能指法打字训练 · 网站版

一个**纯静态**的多文件打字训练网站，含账号注册/登录、首页仪表盘、四大功能模块。

## 目录结构

```
网站版/
├── index.html        # 登录 / 注册页（入口）
├── app.html          # 主应用页（登录后进入）
├── css/
│   └── style.css     # 全站样式
├── js/
│   ├── common.js     # 存储 / 密码哈希 / 会话 / 主题 / 音效
│   ├── data.js       # 指法映射 / 关卡 / 练习 / 成就数据
│   ├── engine.js     # 虚拟键盘 + 手部动画 + 打字引擎
│   ├── auth.js       # 登录注册逻辑
│   └── app.js        # 首页 + 四大模块 + 统计
└── README.md
```

## 如何运行

### 方式一：本地预览（双击）
直接双击 `index.html` 即可在浏览器打开（无需安装任何东西）。

### 方式二：本地静态服务器（推荐，更接近真实发布）
在 `网站版` 目录下任选其一：

```bash
# 使用 Python
python -m http.server 8000
# 使用 Node
npx serve .
# 使用 VS Code 的 Live Server 插件
```

然后浏览器访问 `http://localhost:8000`。

### 方式三：发布到线上
把 `网站版` 目录下的全部文件上传到任意静态托管平台即可：
- **GitHub Pages** / **Gitee Pages**
- **Netlify** / **Vercel** / **Cloudflare Pages**
- 宝塔面板或虚拟主机（把文件放进站点根目录）

> 无需数据库、无需后端环境，纯前端即可运行。

## 账号系统说明

- 采用 **邮箱 + 密码** 注册/登录（你选择的方案）。
- 账号与所有练习数据保存在**浏览器 localStorage** 中，按账号隔离。
- 密码使用 SHA-256 加盐哈希后保存（不存明文）。

### ⚠️ 重要提示（关于"真正的登录"）
纯静态托管方案**没有后端服务器**，因此：
1. 账号只保存在用户自己的浏览器里，**无法跨设备同步**，也无法在服务器端验证。
2. 清除浏览器数据会导致账号和练习记录丢失。
3. 任何人打开本网站都会在**自己的浏览器**里独立注册，彼此看不到对方的数据。

如果需要**真正的多用户账号系统**（服务端校验、跨设备同步、找回密码、QQ 微信第三方登录等），必须接入一个后端（如 Node.js/Express 或 PHP+MySQL）。QQ 登录还需到 [QQ互联](https://connect.qq.com) 申请 AppID/AppKey。如需升级，可在此基础上扩展。

|------|------|
